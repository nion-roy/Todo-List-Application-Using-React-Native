## ✨ মূল বৈশিষ্ট্যসমূহ (Key Features)

- **📝 সহজ ও আকর্ষণীয় টাস্ক ম্যানেজমেন্ট**: যেকোনো কাজের নাম, নির্দিষ্ট ক্যাটাগরি এবং প্রায়োরিটি দিয়ে নিমেষেই টাস্ক যুক্ত করা যায়।
- **🏷️ সুসংগঠিত ৩টি ক্যাটাগরি**:
  - 👤 **ব্যক্তিগত (Personal)**
  - 💼 **অফিস (Work)**
  - 📖 **পড়াশোনা (Study)**
- **⚡ ৩ স্তরের গুরুত্ব (Priority Levels)**:
  - 🔵 **সাধারণ (Low)**
  - 🟡 **মাঝারি (Medium)**
  - 🔴 **জরুরি (High)**
- **🔍 ইনস্ট্যান্ট লাইভ সার্চ**: কাজের শিরোনাম, ক্যাটাগরি বা প্রায়োরিটি লিখে সরাসরি রিয়েল-টাইম সার্চ সুবিধা।
- **📑 স্মার্ট ফিল্টারিং**:
  - `সব কাজ` (All)
  - `চলমান` (Active)
  - `সম্পন্ন` (Completed)
- **📄 পেজিনেশন (Pagination)**: প্রতি পাতায় সুনির্দিষ্ট সংখ্যক কাজ রেখে সহজে নেভিগেট করার সুবিধা।
- **⏳ আধুনিক স্কেলেটন লোডার (Skeleton Loader)**: সার্চ বা পেজ পরিবর্তনের সময় ব্যবহারকারীকে নিখুঁত ও প্রিমিয়াম অভিজ্ঞতার জন্য শিমার/স্কেলেটন লোডিং এফেক্ট।
- **📊 সারাংশ ও অগ্রগতি কার্ড (Stats Card)**: মোট কাজ, সম্পন্ন কাজের সংখ্যা ও অবশিষ্ট কাজের রিয়েল-টাইম হিসাব।
- **🧹 এক ক্লিকে কাজ ডিলিট ও ক্লিয়ার**: একক টাস্ক মুছে ফেলা কিংবা সম্পন্ন হওয়া সমস্ত টাস্ক কনফার্মেশন অ্যালার্টসহ এক ক্লিকে মুছে ফেলা।
- **🇧🇩 শতভাগ বাংলা লোকালাইজেশন**: সংখ্যা এবং সময়ের নোটিফিকেশন (যেমন: `১০:৩০ পূর্বাহ্ন`) সম্পূর্ণ বাংলায় প্রদর্শিত হয়।

## 🚀 যেভাবে চালাবেন (Getting Started)

### ১. পূর্বশর্ত (Prerequisites)
আপনার কম্পিউটারে নিচের সফটওয়্যারগুলো ইনস্টল থাকতে হবে:
- **Node.js** (সংস্করণ ১৮ বা তার পরবর্তী)
- **Git**
- আপনার মোবাইলে **Expo Go** অ্যাপ (Play Store বা App Store থেকে নামিয়ে নিন)

### ২. ডিপেন্ডেন্সি ইনস্টলেশন (Installation)
প্রজেক্টটি ক্লোন করার পর টার্মিনালে নিচের কমান্ডটি চালান:

```bash
npm install
```

### ৩. ডেভেলপমেন্ট সার্ভার শুরু করা (Run the App)
সার্ভার চালু করতে নিচের কমান্ডটি রান করুন:

```bash
npx expo start
```
বা:
```bash
npm start
```

কমান্ডটি চালানোর পর টার্মিনালে একটি **QR Code** দেখতে পাবেন:
- **Android ডিভাইসে**: মোবাইলে `Expo Go` অ্যাপ খুলে QR কোডটি স্ক্যান করুন।
- **iOS ডিভাইসে**: মোবাইলের ডিফল্ট ক্যামেরা অ্যাপ দিয়ে QR কোড স্ক্যান করে Expo Go-তে ওপেন করুন।

## 💻 অন্যান্য প্ল্যাটফর্মে চালানোর কমান্ড (Commands Cheatsheet)

| কমান্ড | কাজ | শর্টকাট |
| :--- | :--- | :---: |
| `npx expo start` | মূল ডেভেলপমেন্ট সার্ভার চালু করে | - |
| `npx expo start --android` | সরাসরি কানেক্টেড অ্যান্ড্রয়েড এমুলেটর বা ডিভাইসে খোলে | `a` |
| `npx expo start --ios` | আইওএস সিমুলেটরে খোলে (macOS প্রয়োজন) | `i` |
| `npx expo start --web` | কম্পিউটারের ব্রাউজারে অ্যাপটির ওয়েব প্রিভিউ খোলে | `w` |
| `npx expo start -c` | মেট্রো ক্যাশ (Metro Cache) ক্লিয়ার করে পুনরায় চালু করে | `r` (রিলোড) |
